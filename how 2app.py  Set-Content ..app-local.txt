[32m +# 🏥 Portal DV Saúde — estado atual[m
[32m +[m
[32m +A aplicação deste repositório é Flask com SQLite (não Django/PostgreSQL). Para desenvolvimento[m
[32m +sem container, `python app.py` inicia o servidor de desenvolvimento; para execução containerizada,[m
[32m +use a seção Docker abaixo, que inicia o Gunicorn. O portal central está em `/` e preserva as[m
[32m +rotas odontológicas existentes.[m
[32m +[m
[32m +| Área | Rotas | Estado implementado |[m
[32m +| --- | --- | --- |[m
[32m +| DV Prontuário | `/prontuario/`, `/prontuario` | Reutiliza o registro SOAP existente |[m
[32m +| DV Odonto | `/odonto/`, `/pacientes`, `/odontograma`, `/agenda`, `/documentos` | Área existente acessível pelo portal |[m
[32m +| DV Farmácia SUS | `/farmacia-sus/` e subrotas | Cadastro de medicamentos, lotes, entradas, saídas, dispensações e relatórios locais |[m
[32m +| DV Gestão Pública | `/gestao-publica/` | Cadastro básico de unidades, profissionais e indicadores existentes |[m
[32m +| DV Integrações | `/integracoes/` | Exibe conectores como não configurados |[m
[32m +| Busca global | `/busca/` | Busca limitada a nomes de pacientes e medicamentos; somente perfil ADMIN |[m

[32m +As rotas de aplicação exigem autenticação, com permissões clínicas, farmacêuticas e administrativas[m
[32m +para as áreas novas. As operações farmacêuticas exigem token CSRF, justificativa, quantidades[m
[32m +positivas e transação SQLite; movimentos concluídos permanecem no histórico e não podem ser apagados[m
[32m +pela interface. Administradores autenticados podem cadastrar contas em `/usuarios`; o cadastro web e[m

[32m +mínimo 12 caracteres e são armazenadas com hash Werkzeug.[m

[32m +`SESSION_COOKIE_SECURE=true` somente quando o site estiver servido por HTTPS. Sem `SECRET_KEY`, a[m

[32m +## Execução local com Docker Desktop e WSL 2[m
[32m +[m
[32m +O container executa a aplicação Flask com Gunicorn, ligado a `0.0.0.0:8000` dentro do[m
[32m +container. No Windows, a porta fica limitada ao próprio computador em[m
[32m +`http://localhost:8000`. O Flask em modo de desenvolvimento (`python app.py`) não é usado[m
[32m +por este fluxo.[m
[32m +[m
[32m +### Preparar e iniciar[m
[32m +[m
[32m +Abra o PowerShell na pasta que contém este README. Crie `.env` uma única vez com uma chave[m
[32m +aleatória privada (não a publique nem a envie ao GitHub):[m
[32m +[m
[32m +```powershell[m
[32m +if (-not (Get-Command docker.exe -ErrorAction SilentlyContinue)) {[m
[32m +    $dockerDir = Join-Path $env:LOCALAPPDATA 'Programs\DockerDesktop\resources\bin'[m
[32m +    if (-not (Test-Path (Join-Path $dockerDir 'docker.exe'))) {[m
[32m +        throw "Docker CLI não encontrado. Verifique a instalação do Docker Desktop."[m
[32m +    }[m
[32m +    $env:PATH = "$dockerDir;$env:PATH"[m
[32m +}[m
[32m +[m
[32m +if (-not (Test-Path .env)) {[m
[32m +    $bytes = New-Object byte[] 32[m
[32m +    $rng = [Security.Cryptography.RandomNumberGenerator]::Create()[m
[32m +    try {[m
[32m +        $rng.GetBytes($bytes)[m
[32m +        $secret = [BitConverter]::ToString($bytes).Replace('-', '').ToLowerInvariant()[m
[32m +        "SECRET_KEY=$secret" | Set-Content -Encoding ascii .env[m
[32m +    }[m
[32m +    finally {[m
[32m +        $rng.Dispose()[m
[32m +        Remove-Variable bytes, rng, secret -ErrorAction SilentlyContinue[m
[32m +    }[m
[32m +} else {[m
[32m +    Write-Host ".env já existe; mantendo a chave atual."[m
[32m +}[m
[32m +```[m
[32m +[m
[32m +Não sobrescreva um `.env` existente; preserve a mesma `SECRET_KEY` entre reinicializações[m
[32m +para manter as sessões válidas. Em seguida, valide e construa antes de iniciar:[m
[32m +[m
[32m +```powershell[m
[32m +New-Item -ItemType Directory -Force .\backups | Out-Null[m
[32m +docker compose config --quiet[m
[32m +docker compose build[m
[32m +docker compose up -d[m
[32m +docker compose ps[m
[32m +Invoke-WebRequest -UseBasicParsing http://localhost:8000/login |[m
[32m +    Select-Object StatusCode[m
[32m +```[m
[32m +[m
[32m +O último comando faz uma requisição HTTP real; o resultado esperado é `200`. O Compose[m
[32m +também marca o serviço como saudável após uma verificação HTTP em `/login`.[m
